韦达定理
在一元二次方程 ax2 + bx + c = 0 中，配方得：
a(x2 + b/a x) = -c
(x2 + 2 × b/2a x + b2/4a2 - b2/4a2) = -c/a
(x2 + 2 × b/2a x + b2/4a2 - b2/4a2) = -c/a
(x + b/2a)2 = -c/a + b2/4a2
(x + b/2a)2 = (b2 - 4ac)/4a2
x + b/2a = ± [√(b2 - 4ac)]/2a
x = -b/2a ± [√(b2 - 4ac)]/2a
x = [-b ± √(b2 - 4ac)]/2a

这时候我们再求 x1 + x2 和 x1 · x2时：
x1 + x2 = [-b + √(b2 - 4ac)]/2a + [-b - √(b2 - 4ac)]/2a
= (-2b)/2a
= -b/a
x1 · x2 = [-b + √(b2 - 4ac)]/2a · [-b - √(b2 - 4ac)]/2a
= 4ac/4a2
= c/a
