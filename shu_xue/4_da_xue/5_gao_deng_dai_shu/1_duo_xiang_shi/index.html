第一节、数域
乘方：一般地，将 n 个 a 相乘的运算叫做 乘方。
幂：n 个 a 相乘记作 an，乘方的结果叫做幂。
an 读作 “a 的 n 次方”。
当 an 被看作是 a 的 n 次方的结果时，也读作 “a 的 n 次幂”。
n = 1 时，我们规定：a1 = a。
底数：在 an 中，a 叫做 底数。
指数：在 an 中，正整数 n 叫做 指数。
